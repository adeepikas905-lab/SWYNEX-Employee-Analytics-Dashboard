# SWYNEX Employee Analytics Dashboard

## Project Overview
This project focuses on creating an interactive Employee Analytics Dashboard using Microsoft Power BI. It helps analyze employee data and present important information through visualizations.

## Objectives
- Analyze total employee count.
- Understand department-wise employee distribution.
- Visualize gender distribution, if available in the dataset.
- Analyze average salary, if salary data is available.
- Use interactive slicers to filter the dashboard.

## Tools Used
- Microsoft Power BI
- Power Query for data cleaning and transformation
- GitHub for project submission

## Dashboard Features
- Employee summary cards
- Department-wise charts
- Interactive filters and slicers
- Clear and easy-to-understand visualizations

## Files Included
- Power BI dashboard (.pbix)
- Dataset used for the analysis, if permitted
- Dashboard screenshot

## How to Use
1. Download the Power BI (.pbix) file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Interact with the slicers to explore the employee data.

## Project Outcome
This dashboard demonstrates basic data analysis, data visualization, and interactive reporting skills using Power BI.
